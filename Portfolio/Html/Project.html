Project Name: Game Shooter

Language Used: C++

Project Description:

Space Shooter is a C++ game developed using OpenGL. The game provides an interactive space-shooting environment where the player controls a spaceship, shoots enemies, and progresses through multiple levels. The project concepts such as 2D object rendering, keyboard interaction, collision handling, sound effects, and game-level management. The game includes five levels where each level becomes harder, along with a high-score system and supporting game resources
